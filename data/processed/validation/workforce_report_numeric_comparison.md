# Workforce Report Numeric Comparison

## Key conclusion

The current dashboard strongly matches the Workforce report on regional population scale, South San Diego economic distress, Metro as the largest hub, and wraparound-service distribution. It only partially matches the report on North County's economic strength and East San Diego's education weakness. The biggest current mismatch is that North County is now the lowest overall YOI region because of a very low Youth Supports score.
